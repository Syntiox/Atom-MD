## 📖 What is Atom-MD?

**Atom-MD** is a powerful WhatsApp automation bot that runs 24/7 on cloud servers, managed entirely by the **Syntiox** team. You don't need to install anything, write any code, or manage any server — simply **connect your WhatsApp number** and control everything from a beautiful web dashboard.

Once connected, Atom-MD supercharges your WhatsApp with AI chat, privacy protection, auto-replies, media downloading, and much more — all running silently in the background while you go about your day.

## 🚀 Getting Started (Connect Your Bot)

Getting your bot up and running takes less than **2 minutes**. Here's how:

### Step 1: Log In to Syntiox
Before connecting your bot, you need a **Syntiox account**. Go to **[atom.syntiox.top](https://atom.syntiox.top)** and sign in or create a free account. You can sign up directly from the Atom-MD website itself — no need to go anywhere else.

> 💡 This is a one-time step. Once you have a Syntiox account, you'll always be logged in.

### Step 2: Open the Dashboard
After logging in, navigate to the **[Dashboard](https://atom.syntiox.top/dash)** to start connecting your WhatsApp.

### Step 3: Connect Your WhatsApp
You have **two options** to connect:

| Method | How It Works |
|---|---|
| **📷 QR Code** | A QR code appears on screen. Open WhatsApp → **Linked Devices** → **Link a Device** → Scan the QR. |
| **🔢 Pairing Code** | Enter your phone number (with country code, e.g., `94771234567`). You'll receive an 8-digit code — enter it in WhatsApp → **Linked Devices** → **Link with Phone Number**. |

### Step 4: Receive Your Password
Once connected, Atom-MD will automatically send you a message in your WhatsApp inbox containing:
- ✅ Your **Bot Number** (the session identifier)
- 🔑 Your **Dashboard Password**

> ⚠️ **Save this password!** You need it every time you log into the dashboard. If you lose it, type `.password` in your WhatsApp to retrieve it again.

### Step 5: Log Into the Dashboard
Go back to **[atom.syntiox.top](https://atom.syntiox.top)**, enter your **Bot Number** and **Password**, and you're in! 🎉

### ⚙️ System Settings Panel

| Setting | What It Does |
|---|---|
| **Work Mode** | `Public` = anyone can use commands. `Private` = only you (the bot owner) can use commands. |
| **Command Prefix** | The symbol before commands. Default is `.` (dot). You can change it to `!`, `/`, `#`, etc. |
| **Bot Footer** | Custom text that appears at the bottom of every bot message (e.g., `> Powered by Atom-MD`). |
| **Always Offline** | Makes your WhatsApp appear offline 24/7 even while the bot is fully active and responding. |
| **Fake Typing / Recording** | When someone messages you, the bot simulates "typing..." or "recording audio..." before replying. Makes it look natural. |

> 💡 **Note:** "Always Offline" and "Fake Typing" are mutually exclusive — you can only enable one at a time.

### 🛡️ Privacy Panel

This is where Atom-MD truly shines as your privacy guardian:

| Setting | What It Does |
|---|---|
| **Anti-Delete** | When someone deletes a message they sent you, the bot recovers it and forwards the original message back to you. You'll never miss a deleted message again. |
| **Anti-Delete To Me** | `ON` = recovered messages are sent to your own inbox (privately). `OFF` = recovered messages are sent back to the same chat where they were deleted. |
| **Anti-Edit** | When someone edits a message, the bot captures and shows you the **original text before the edit**, so you can see what was changed. |
| **Anti-Edit To Me** | Same as above — controls whether the original is sent to your inbox or the same chat. |
| **Anti-ViewOnce** | When someone sends you a view-once photo/video, the bot intercepts and saves it before it disappears. |
| **Anti-ViewOnce To Me** | Controls where the recovered view-once media is forwarded. |
| **Anti-Delete Status** | Recovers deleted WhatsApp status updates (stories) and forwards them to your inbox. |
| **Anti-Call** | Automatically rejects incoming WhatsApp calls and sends a custom message to the caller. |
| **Anti-Call Mode** | `All` = blocks all calls. `Selected` = only blocks calls from specific numbers you define. |
| **Anti-Call Numbers** | If mode is "Selected", list the numbers to block (comma-separated, e.g., `94771234567, 94779876543`). |
| **Anti-Call Message** | The custom message sent to blocked callers (e.g., "🚫 Calls are not allowed. Please text me."). |

### 💬 Auto Replies Panel

Set up **up to 6 smart auto-reply rules** that trigger when someone sends you a message containing specific keywords.

#### How to Set Up an Auto Reply:

1. Click **"+ Add Auto Reply"**
2. Fill in:
   - **Trigger Keyword** — The word(s) that trigger this reply. You can add multiple keywords separated by commas. Example: `hi, hello, hey, hlo, kohomada`
   - **Reply Text** — The message the bot will send back automatically.
   - **Image URL** *(optional)* — If you want to send an image along with the reply, paste an image URL or upload one.
3. Toggle the **switch** to enable/disable each reply individually.
4. Click **Save**.

#### Important Notes About Keywords:
- **Case-insensitive:** `Hello`, `HELLO`, and `hello` all match the same keyword.
- **Partial matching:** If your keyword is `hi`, it will also trigger for messages like "hi bro", "thinking", etc. (because they contain "hi"). For exact word matching, use more specific keywords.
- **Emoji support:** You can use emojis as keywords! Setting `🔥` as a keyword will trigger when someone sends a 🔥 in their message.
- **Status replies:** If someone replies to your WhatsApp status with a message containing your keyword, the auto-reply will trigger too!
- **Smart cooldown:** Each auto-reply has a built-in **5-hour cooldown per contact** to prevent spamming the same person repeatedly.

## 🔒 Privacy & Security

Atom-MD takes your security seriously:

- 🔐 **Dashboard authentication** uses HMAC-SHA256 time-based tokens — your session cannot be hijacked
- 🤖 **Bot protection** via Cloudflare Turnstile on pairing endpoints
- 🏗️ **Session isolation** — every user's data is completely separated; no cross-contamination
- 👻 **Ghost Mode** — the bot stays invisible (offline) even while fully active
- 📵 **No read receipts** — messages are processed without triggering blue ticks
- 🔑 **Password protected** — only you can access your dashboard with your unique password

## ❓ Frequently Asked Questions (FAQ)

<details>
<summary><b>How do I connect my WhatsApp to Atom-MD?</b></summary>

Go to [atom.syntiox.top](https://atom.syntiox.top), click "Connect", and either scan the QR code or use a pairing code. See the [Getting Started](#-getting-started-connect-your-bot) section above for detailed steps.
</details>

<details>
<summary><b>Is my WhatsApp data safe?</b></summary>

Yes. Atom-MD only processes messages to provide the features you enable. Your session credentials are encrypted and stored securely. We do not read, store, or share your personal messages.
</details>

<details>
<summary><b>I lost my dashboard password. How do I get it back?</b></summary>

Simply type `.password` in any WhatsApp chat. The bot will send your number and password to your inbox immediately.
</details>

<details>
<summary><b>Can I change the command prefix from "." to something else?</b></summary>

Yes! Go to Dashboard → System Settings → **Command Prefix** and change it to any character you prefer (e.g., `!`, `/`, `#`, `$`).
</details>

<details>
<summary><b>How many auto-replies can I set up?</b></summary>

You can set up **up to 6 auto-reply rules**, each with its own keywords, reply text, and optional image.
</details>

<details>
<summary><b>Can I use multiple keywords for one auto-reply?</b></summary>

Yes! Separate keywords with commas. Example: `hi, hello, hey, sup` — any of these words in a message will trigger the same auto-reply.
</details>

<details>
<summary><b>Will the auto-reply spam the same person?</b></summary>

No. There's a built-in **5-hour cooldown** per contact per auto-reply slot. The same person won't receive the same auto-reply more than once every 5 hours.
</details>

<details>
<summary><b>Can I use emojis as auto-reply keywords?</b></summary>

Yes! You can use emojis like `🔥`, `❤️`, `👍` as keywords. If someone sends a message containing that emoji, the auto-reply triggers.
</details>

<details>
<summary><b>Does Anti-Delete work for group messages?</b></summary>

Currently, Anti-Delete and Anti-Edit work in **private (DM) chats only**. Group support may be added in future updates.
</details>

<details>
<summary><b>How do I get a free Gemini API key for AI features?</b></summary>

1. Go to [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. Sign in with your Google account
3. Click "Create API Key"
4. Copy the key and paste it in Dashboard → AI Settings → API Key
</details>

<details>
<summary><b>Why are media downloads redirected to the Premium Bot?</b></summary>

Some server nodes have strict bandwidth limits. To ensure 24/7 stability for all users, large media downloads may be redirected to our Premium Bot which has unlimited bandwidth.
</details>

<details>
<summary><b>Can I make the bot respond only to me?</b></summary>

Yes! Set **Work Mode** to `Private` in Dashboard → System Settings. In private mode, only you (the bot owner) can use commands. Everyone else is ignored.
</details>

<details>
<summary><b>What does "Always Offline" do?</b></summary>

It keeps your WhatsApp status as "Offline" 24/7, even while the bot is actively reading and responding to messages. Nobody can see you as "Online" or your "Last Seen".
</details>

<details>
<summary><b>Can I set multiple emojis for status reactions?</b></summary>

Yes! In Dashboard → Automations → **Status Emoji**, enter multiple emojis separated by commas (e.g., `💚, ❤️, 🔥, 😍, 🤩`). The bot will randomly pick one each time to look natural.
</details>

<details>
<summary><b>What is the ".vv" command and how does it work?</b></summary>

When someone sends you a **view-once** photo or video, reply to it with **3 or more emojis** (e.g., `🔥🔥🔥`). The bot will recover the media and send it back to you as a normal message you can view anytime.
</details>

<details>
<summary><b>My bot disconnected. What should I do?</b></summary>

The bot auto-reconnects in most cases. If it doesn't, go to [atom.syntiox.top](https://atom.syntiox.top) and reconnect using QR or pairing code. Your settings and auto-replies are saved and will restore automatically.
</details>
